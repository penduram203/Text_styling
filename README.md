# Text Styling Extension

チャット内テキストの見た目（`<p>` `<q>` `<em>` タグごとの文字サイズ・太さ・色・
縁取り・行間・透過度）と、チャットウインドウ自体の背景透過度を細かく調整できる
SillyTavern拡張機能です。

## 主な機能

- `<p>` / `<q>` / `<em>` タグごとに独立したスタイル設定（有効/無効、サイズ、太さ、
  文字色、縁取り色・幅、行間、透過度）
- チャットウインドウの背景透過度調整
- チャットウインドウの位置プリセット（中央寄せ／右半分）ボタン
- 設定パネルの表示/非表示切替（左下の⚙️アイコン）

## インストール方法

1. SillyTavernの拡張機能パネルを開く
2. 「拡張機能をインストール」をクリック
3. このリポジトリのURLを貼り付けて保存

## 設定の保存について

設定は現在ブラウザの`localStorage`（キー: `textStylingSettings_v6_modified`）に
保存されています。ブラウザやプロファイルを変えると設定は引き継がれません。
